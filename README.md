# Qimat Android v1.2.2

نسخه اندروید برنامه «قیمت» بر پایه نسخه نهایی تأییدشده `Qimat_v1_2_2_NoLeftPanel`.

## امکانات

- محاسبه قیمت طلا بر اساس قیمت روز، وزن و درصد اجرت
- اعمال حداقل اجرت تعریف‌شده برای هر نوع کالا
- محاسبه سود و مالیات بر اساس منطق نسخه نهایی
- مدیریت انواع کالا و متعلقات
- رابط فارسی راست‌به‌چپ با تم کرم، قهوه‌ای و طلایی

فایل APK با GitHub Actions ساخته می‌شود و در بخش Artifacts اجرای `Build Android APK` قرار می‌گیرد.
